# TrackerOne 解析レポート（第1版：公開情報ベース）

作成日: 2026-10-24
対象: https://play.google.com/store/apps/details?id=com.ww.trackerone

## 1. アプリの正体

| 項目 | 内容 |
|---|---|
| 正式名 | TrackerOne（パッケージ名 `com.ww.trackerone`） |
| 開発元 | Shanghai WanWay Tech Co.,Ltd（中国・上海の GPS 発信機メーカー） |
| ダウンロード | 10万+ / 評価 3.9（32件） |
| カテゴリ | ツール |
| 課金 | アプリ内購入あり（「Renewal」＝回線・プラットフォーム利用料の更新） |
| 最終更新 | 2026/10/10 |
| データ | 位置情報を第三者と共有する場合あり、個人情報（メール等）を収集 |

**重要:** TrackerOne は「スマホの位置を追跡するアプリ」ではありません。
**WanWay 社製の GPS 発信機（車やバイク、荷物に付ける小型端末）の位置を、スマホで見るための閲覧アプリ**です。

```
[GPS発信機] --(SIM回線/TCP)--> [WanWayのクラウドサーバー] --(API)--> [TrackerOneアプリ]
  車両に設置                     位置の保存・アラーム判定           地図表示・操作
```

つまり「同等のアプリ」を作るには、アプリ単体ではなく **発信機・サーバー・アプリの3点セット** が必要です。

## 2. 機能一覧（ストア説明・スクリーンショットより）

### 画面1: 地図（ホーム）
- 上部タブ「Map / list」（地図表示と端末一覧の切替）
- 右上にベル（アラーム通知、未読バッジ付き）、左上にアカウント
- 地図上に端末の現在位置とラベル
- 地図種別切替、交通情報レイヤー、前後の端末切替（▲▼）、現在地へ移動ボタン
- 下部カード:
  - 端末名＋状態（例: `Static 23min15sec` ＝停車して23分15秒）
  - 住所（逆ジオコーディング）
  - **GPS 受信強度 / ACC（エンジンON/OFF）/ 電池残量 %**
- 下部メニュー: Playback（再生）/ Details（詳細）/ Share（位置共有）/ Settings（設定）

### 画面2: 走行履歴の再生（Playback）
- 地図上に走行ルート（緑線）、出発・到着ピン、停車ポイントの番号マーカー
- 日付選択（時計アイコン）、履歴のダウンロード
- 下部: 測位時刻、総走行距離、日付、速度
- 再生/一時停止、シークバー、再生速度切替（Medium など）

### 画面3: マイページ
- ログインアカウント（メールアドレス）
- **Binding**: 発信機の IMEI を登録して自分のアカウントに紐づけ
- **Renewal**: 利用料の更新（アプリ内課金）
- カスタマーサービス / ログ送信 / フィードバック / アプリについて

### ストア説明に書かれたその他の機能
- **ジオフェンス**: 指定エリアへの出入りで通知
- **アラーム統計**: 振動・電源切断・速度超過・低電池などのアラーム履歴
- **コマンド送信**: 端末へ遠隔命令（例: 燃料・電源カット、測位間隔変更、再起動）
- 停車履歴（滞在トレース）の取得

## 3. 無料で同等品を作る方法

### 結論: オープンソースの **Traccar** を土台にするのが最短・無料

Traccar（https://www.traccar.org）は無料・オープンソースの GPS 追跡サーバーで、200種類以上の発信機プロトコルに対応しています。
Traccar フォーラムでは **WanWay の端末（S20, GS05, GS10 など）は GT06 プロトコル互換** と報告されています。

| 部品 | 無料の選択肢 | 役割 |
|---|---|---|
| 発信機 | 手持ちの WanWay 端末、または GT06 互換の安価な端末 | 位置送信 |
| サーバー | Traccar（自宅PC / Oracle Cloud 無料枠などで運用） | 位置保存、ジオフェンス、アラーム、コマンド送信、REST API |
| 地図 | OpenStreetMap（無料） | 地図表示 |
| 住所変換 | Nominatim（OSM の無料サービス）など | 住所表示 |
| 通知 | Firebase Cloud Messaging（無料） | プッシュ通知 |
| アプリ | 自作（Flutter など）で日本語 UI | TrackerOne と同じ画面構成 |

Traccar 自体にも公式の無料アプリ「Traccar Manager」（日本語対応あり）があるため、まずはそれで動作確認し、その後 TrackerOne 風の日本語アプリを自作する、という2段階が安全です。

### 注意点
- 発信機には **SIM カード（通信費）** が必要。ここだけは完全無料にはできません（格安の IoT SIM で月100〜300円程度）。
- 発信機の送信先サーバーを WanWay から自分の Traccar に変える必要があります（通常は SMS コマンドで設定）。
- フォーラムでは「停車中は座標0を送る」端末の報告もあり、実機での確認が必要です。
