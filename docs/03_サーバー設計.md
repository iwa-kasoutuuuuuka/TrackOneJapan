# TrackOneJapan サーバー設計（Windows 11 常時稼働 PC 版）

作成日: 2026-10-24
対象: 自宅などに置いた **常時起動の Windows 11 PC 1台** で、GPS 発信機の位置を24時間記録するサーバー

---

## 1. 方針

| 方針 | 内容 |
|---|---|
| 完全無料 | ソフトはすべて無料・オープンソース、または無料プラン（SIM 通信費だけは別） |
| 1台で完結 | サーバーソフトはすべて本番 PC 1台に入れる |
| 手作業を減らす | インストール・設定・バックアップ・監視を PowerShell スクリプトで自動化 |
| 止まりにくくする | すべて Windows サービスとして動かし、再起動・停電復帰後も自動で立ち上がる |
| 安全 | 管理画面（Web）はインターネットに直接開けず、HTTPS のトンネル経由でのみ公開 |

## 2. 全体構成

```
                         携帯回線 / インターネット
 ┌──────────────┐  TCP(GT06)   ┌────────────────────────────────────────────┐
 │ GPS 発信機     │────────────▶│ 自宅ルーター                                 │
 │ (WanWay)      │  ドメイン:ポート │  ポート転送  外部ポート → 本番PC:5023       │
 └──────────────┘ (DuckDNS)    └───────────────┬────────────────────────────┘
                                                 │ LAN
 ┌──────────────┐  HTTPS        ┌───────────────▼────────────────────────────┐
 │ スマホアプリ    │────────────▶│ 本番 PC（Windows 11, 常時起動）               │
 │ / ブラウザ     │ xxx.ts.net   │                                            │
 └──────────────┘ (Tailscale    │  [Tailscale] ── Funnel(HTTPS) ──┐           │
                    Funnel)      │                                 ▼           │
                                 │  [Traccar サービス]  Web/API 127.0.0.1:8082 │
                                 │        │            GT06 受信  0.0.0.0:5023 │
                                 │        ▼                                    │
                                 │  [PostgreSQL サービス] 127.0.0.1:5432       │
                                 │                                            │
                                 │  タスクスケジューラ:                          │
                                 │   ・DuckDNS 更新（5分ごと）                    │
                                 │   ・死活監視・自動復旧（5分ごと）                │
                                 │   ・DB バックアップ（毎日 3:00）               │
                                 └────────────────────────────────────────────┘
```

### 通信経路は2本

| 経路 | 用途 | 方式 | 理由 |
|---|---|---|---|
| ① 発信機 → サーバー | 位置の受信 | ルーターのポート転送 + DuckDNS（無料の固定ドメイン） | 発信機は独自の TCP 通信（GT06）しか話せないため、直接つなぐしかない |
| ② アプリ → サーバー | 地図表示・操作 | Tailscale Funnel（無料の HTTPS 公開） | ポート開放不要、HTTPS 証明書も自動。パスワードが暗号化されずに流れるのを防ぐ |

## 3. 使用ソフト

| ソフト | バージョン | 役割 | 入れ方 |
|---|---|---|---|
| Traccar | 6.16.0（2026-09 最新） | GPS 追跡サーバー本体（Java 同梱） | GitHub 公式リリースの Windows 版をサイレントインストール |
| PostgreSQL | 17 | 位置・設定の保存 | winget（`PostgreSQL.PostgreSQL.17`） |
| Tailscale | 最新 | アプリ用の HTTPS 公開（Funnel） | winget（`Tailscale.Tailscale`） |
| DuckDNS | Web サービス | 無料ドメイン（自宅 IP が変わっても追従） | スクリプトで定期更新 |

### なぜ PostgreSQL か
Traccar 標準の H2 データベースは手軽ですが、公式に「本番非推奨」とされ、停電などで壊れた報告が多くあります。PostgreSQL は Windows サービスとして安定して動き、バックアップも標準機能（`pg_dump`）でできます。

### Traccar の設定（traccar.xml の要点）
| 設定 | 値 | 意味 |
|---|---|---|
| `database.*` | PostgreSQL（localhost） | DB 接続 |
| `web.address` | `127.0.0.1` | 管理画面を PC 内だけに限定（外へは Tailscale 経由） |
| `web.port` | `8082` | Web/API ポート |
| `protocols.enable` | `gt06,osmand` | 使う通信方式だけ受け付ける（GT06=発信機、OsmAnd=スマホでのテスト用） |
| `gt06.port` | `5023` | 発信機の受信ポート |
| `geocoder.*` | Nominatim、`ja` | 住所を日本語で表示。Traccar 6 の初期設定どおり、位置ごとではなく**画面・アプリが求めたときだけ**変換する（Nominatim の利用規約「1秒1回まで」を守るため） |
| `logger.rotate` | `true` | ログを日ごとに分割 |

> Traccar をアップデートすると `conf\traccar.xml` が初期状態に戻るため、設定の原本は `C:\TrackOneServer\config\traccar.xml` に置き、インストール・更新のたびにスクリプトがコピーし直します。

## 4. 本番 PC の要件

| 項目 | 推奨 |
|---|---|
| OS | Windows 11（Home / Pro どちらでも可） |
| CPU / メモリ | 2コア以上 / 8GB 以上（Traccar + PostgreSQL で 1〜2GB 程度使用） |
| ストレージ | 空き 20GB 以上（発信機1台・10秒間隔で年間 数GB 程度） |
| ネットワーク | **有線 LAN 推奨**。ルーターで本番 PC の IP を固定（DHCP 予約） |
| 電源 | BIOS/UEFI の「AC 電源復帰時に自動起動（Restore on AC Power Loss）」を ON |
| ほかの用途 | 普段使いの PC と兼用も可。ただしシャットダウンしないこと |

インストールスクリプトが自動で行う Windows 設定:
- 電源プラン: スリープ・休止状態を無効（画面オフは可）
- Windows Update: アクティブ時間を設定（日中は再起動しない）。再起動してもサービスは自動起動
- ファイアウォール: 受信 TCP 5023（GT06、すべてのネットワーク）と TCP 5055（OsmAnd、テスト送信用。プライベート ネットワーク＝LAN 内のみ）を許可
  （インターネットに公開するのはルーターでポート転送する 5023 だけ）

## 5. ネットワーク（いちばん重要な確認事項）

発信機からの接続を受けるには、**ルーターでポート転送ができる回線**である必要があります。日本の光回線は接続方式で次のように分かれます。

| 接続方式 | 例 | ポート転送 | 対応 |
|---|---|---|---|
| PPPoE（グローバル IPv4） | 従来型のプロバイダ接続 | ◎ 自由に可能 | そのまま使える |
| IPv4 over IPv6（MAP-E） | v6プラス、OCN バーチャルコネクト | △ 割り当てられた一部のポートのみ | **使えるポート番号を発信機に設定すれば可**（発信機のポートは SMS で自由に指定できる） |
| IPv4 over IPv6（DS-Lite） | transix、クロスパス | × 不可 | 下の「代替案」へ |
| モバイルルーター / CGNAT | ホームルーター、格安 SIM 回線 | × 不可 | 下の「代替案」へ |

確認方法は [04_サーバー構築手順.md](04_サーバー構築手順.md) の「手順0」に記載。

### 代替案（ポート転送できない回線の場合）
Oracle Cloud の無料枠（Always Free）に小さな仮想サーバーを作り、**中継役**にする。発信機は中継サーバーにつなぎ、中継サーバーから Tailscale 経由で自宅 PC に転送する。データは自宅 PC に残る構成。必要になった時点で別途設計する。

## 6. 運用設計

### 自動起動と復旧
| 仕組み | 内容 |
|---|---|
| Windows サービス | `traccar` / `postgresql-x64-17` / `Tailscale` をすべて「自動」起動に設定。失敗時は自動再起動（サービスの回復設定） |
| 死活監視（5分ごと） | サービス停止・5023 ポート無応答（gt06 を使う設定の場合）・Web API 無応答を検知したら再起動し、ログに記録。Traccar が 2 分で止まらなければプロセスを強制終了してから起動 |
| メンテナンス中 | install / restore / update-traccar / rotate-db-password の実行中は `state\maintenance.flag` を置き、死活監視は何もしない（2 時間以上前の目印で、実行していた処理も終わっていれば消し忘れとみなして無視） |
| 復元失敗時 | `state\restore-failed.flag` を置き、Traccar を止めたままにする（空のデータベースで動き出さないように）。死活監視も Traccar を起動しない |
| 停電対策 | BIOS で AC 復帰時自動起動 + サービス自動起動。可能なら小型 UPS |
| Tailscale | `tailscale up --unattended` でログインし、再起動後に誰も Windows にログインしなくても Funnel が動くようにする |

### バックアップ
| 項目 | 内容 |
|---|---|
| 対象 | PostgreSQL の Traccar データベース全体（位置履歴・端末・ジオフェンス・ユーザー）と `traccar.xml` |
| 方法 | `pg_dump`（カスタム形式・圧縮） |
| 頻度 | 毎日 3:00 |
| 保存先 | `C:\TrackOneServer\backup`（14日分保持、管理者と SYSTEM のみ読める）。設定で別ドライブや OneDrive フォルダへのコピーも可（コピー先が外れていても警告だけで、古いバックアップの削除は行う） |
| 保持期間の判断 | ファイル名の日時（`traccar-YYYYMMDD-HHMMSS.dump`）で判断する。コピー先でも同じ名前の形式のファイルだけを削除 |
| 復元 | `restore.ps1 -BackupFile <ファイル>` で復元。復元前の状態を `backup.ps1 -NoPrune`（古いバックアップを消さない）で保存し、データベースを作り直してから `pg_restore --single-transaction --exit-on-error` で復元（途中で失敗したら全体を取り消す） |

### 更新
`update-traccar.ps1 -Version 6.x.x` で、ダウンロード → バックアップ → 停止 → インストール → 設定再適用 → 起動 → 動作確認 を自動実行。
ダウンロードに失敗した場合は Traccar を止めずに中止し、途中で失敗した場合も設定を入れ直して Traccar の起動を試みる。
成功すると `config.psd1` の `TraccarVersion` も書き換える。install.ps1 はインストール済みより古いバージョンへの入れ替えを拒否する（`-AllowDowngrade` で許可、入れ替え前に自動バックアップ）。

### 設定ファイル
install.ps1 は 2 回目以降、インストール済みの `C:\TrackOneServer\config\config.psd1` を使う（`-ConfigPath` を指定したときだけ上書き）。

### ログ
| ログ | 場所 | 保存期間 |
|---|---|---|
| Traccar | `C:\Program Files\Traccar\logs\tracker-server.log`（日ごと） | 30 日（backup.ps1 が削除） |
| PostgreSQL | `C:\Program Files\PostgreSQL\17\data\log` | 30 日（backup.ps1 が削除） |
| スクリプト（監視・バックアップ・DuckDNS・更新） | `C:\TrackOneServer\logs\` | 90 日 |

## 7. オリジナルアイコン

TrackerOne とは別の、オリジナルのアイコンを使います（紺の角丸 + 白い位置ピン + 日の丸の赤 + 走行ルートの点線）。

| 使う場所 | 仕組み |
|---|---|
| 管理画面のタブのアイコン・スマホのホーム画面アイコン | Traccar の `web.override` フォルダで `favicon.ico` / `pwa-*.png` 等を上書き |
| ログイン画面のロゴ・タイトル・テーマ色 | Traccar のサーバー属性 `logo` / `logoInverted` / `title` / `colorPrimary` を install.ps1 がデータベースに設定 |
| 本番 PC のデスクトップ | 「TrackOne 管理画面」ショートカット（`trackone.ico`） |
| 今後の日本語アプリ | 同じアイコン（`assets/icon/`）を使用 |

## 8. セキュリティ

| 対策 | 内容 |
|---|---|
| 公開範囲を最小化 | インターネットに開くのは GT06 受信ポートのみ。管理画面・DB は PC 内限定 |
| HTTPS | アプリ・ブラウザからは Tailscale Funnel（正規の証明書付き HTTPS）経由のみ |
| パスワード | DB パスワードはインストール時に自動生成し、管理者だけが読めるファイルに保存。PostgreSQL のインストールで winget のログに残る初期パスワードは、インストール直後に変更する。`rotate-db-password.ps1` でいつでも変更可 |
| フォルダの権限 | `C:\TrackOneServer` は親（C:\）の権限を引き継がず、管理者と SYSTEM のみフルコントロール。一般ユーザーは scripts / config / web-override とアイコンを読めるだけ（SYSTEM で動くスクリプトを書き換えられない）。backup / secrets / state は管理者と SYSTEM のみ。logs はインストールした人も読める |
| 不明な端末 | Traccar に登録していない IMEI からのデータは記録しない（既定動作） |
| 管理者アカウント | 最初に登録したユーザーが管理者。2 人目以降の自由登録は Traccar 6.16 の初期設定で無効（テストで確認済み） |
| リポジトリ | パスワード・トークン・APK は Git に含めない（`.gitignore`） |

## 9. ファイル構成

### リポジトリ（GitHub）
```
server/windows/
  config.example.psd1    設定ファイルのひな形（コピーして config.psd1 を作る）
  install.ps1            一括インストール（何度実行しても安全）
  traccar.xml.template   Traccar 設定のひな形
  update-traccar.ps1     Traccar の更新
  backup.ps1             DB バックアップ
  restore.ps1            DB 復元
  healthcheck.ps1        死活監視・自動復旧
  duckdns-update.ps1     DuckDNS の IP 更新
  rotate-db-password.ps1 DB パスワードの変更
  common.ps1             共通処理
  trackone.ico           オリジナルアイコン（デスクトップのショートカット用）
  web-override/          管理画面のファビコン・ホーム画面アイコン・ロゴ
assets/icon/             オリジナルアイコンの原本（SVG）と各サイズの PNG
```

### 本番 PC（インストール後）
```
C:\TrackOneServer\
  config\config.psd1      本番設定（ポート・ドメイン等）
  config\traccar.xml      Traccar 設定の原本
  secrets\                DB パスワード・DuckDNS トークン（管理者のみ読める）
  scripts\                上記スクリプト一式
  web-override\           管理画面のアイコン・ロゴ（Traccar が配信）
  backup\                 DB バックアップ（管理者のみ読める）
  state\                  Traccar のバージョン・監視の状態・メンテナンス中の目印
  logs\                   スクリプトのログ
C:\Program Files\Traccar\  Traccar 本体
C:\Program Files\PostgreSQL\17\  PostgreSQL 本体
```
