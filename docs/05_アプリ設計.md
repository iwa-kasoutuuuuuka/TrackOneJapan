# TrackOne Japan スマホアプリ設計

作成日: 2026-10-24
前提: サーバーは [03_サーバー設計.md](03_サーバー設計.md) の Traccar（Windows 11 PC + Tailscale Funnel で HTTPS 公開）
画面イメージ: [mockups/app-mockups.png](mockups/app-mockups.png)

---

## 1. 方針

| 方針 | 内容 |
|---|---|
| TrackerOne と同等 | 地図・一覧・端末カード・履歴再生・アラーム・ジオフェンス・コマンド・位置共有・端末設定をそろえる |
| 日本語ファースト | 画面・通知・日付・単位（km、km/h）・住所をすべて日本語表記 |
| 完全無料 | 開発ツール・ライブラリ・地図・通知すべて無料のものだけを使う |
| オリジナルアイコン | ホーム画面アイコン・起動画面・通知アイコン・地図上の端末アイコンまで自作 |
| 作らないもの | 課金（更新料）、ペット・OBD 専用画面、メーカー独自のクラウド連携 |

---

## 2. 対応端末と配布方法（無料の範囲）

| 対象 | 方法 | 費用 |
|---|---|---|
| **Android（主対象）** | 自作アプリの APK ファイルを GitHub の Releases に置き、スマホで直接インストール | 無料 |
| Android（任意） | Google Play で配布する場合は開発者登録が必要 | 登録料 25 ドル（1回のみ）※使わなくてよい |
| iPhone | アプリとしての配布は Apple の開発者登録（年額）が必要なため**対象外**。代わりに Traccar の Web 画面を Safari で開き「ホーム画面に追加」すれば、オリジナルアイコン付きで使える（サーバー側で対応済み） | 無料 |

> 技術的には同じソースから iPhone 版も作れるため、将来有料登録した場合はそのまま iPhone 版を出せる構成にしておく。

## 3. 技術選定

| 項目 | 採用 | 理由 |
|---|---|---|
| フレームワーク | **Flutter**（Dart） | 無料。1つのソースで Android / iPhone 両対応。地図・通知のライブラリが充実 |
| 状態管理 | Riverpod | 定番で、リアルタイム更新との相性がよい |
| 画面遷移 | go_router | 通知タップから特定画面を開く処理が書きやすい |
| 通信 | dio + cookie_jar | Traccar のセッション（Cookie）をそのまま扱える |
| リアルタイム | web_socket_channel | Traccar の `/api/socket` で位置・端末状態・イベントを即時受信 |
| 地図 | **flutter_map**（無料・API キー不要） | Google Maps SDK は課金アカウント登録が必要なため使わない |
| 地図タイル | **地理院タイル（国土地理院）**標準地図・淡色地図・航空写真 ／ OpenStreetMap Japan（日本語表記） | どちらも無料・登録不要。出典表示が条件 |
| プッシュ通知 | **Firebase Cloud Messaging**（無料プラン） | Traccar 標準の `firebase` 通知機能と直結できる。クレジットカード登録不要 |
| 安全な保存 | flutter_secure_storage | ログイン用トークンを暗号化して保存 |
| 共有 | share_plus | 位置共有リンクを LINE・メール等で送る |
| SMS 連携 | url_launcher（`sms:` を開く） | 発信機への SMS コマンドをスマホの SMS アプリで送る（TrackerOne と同じ方式） |
| 多言語 | flutter_localizations + intl（`ja`） | 日本語のみ。将来ほかの言語も足せる作り |
| アイコン | flutter_launcher_icons / flutter_native_splash | オリジナルアイコンからホーム画面アイコン・起動画面を自動生成 |

## 4. 全体構成

```
┌──────────────── スマホ（Android）────────────────┐
│  TrackOne Japan アプリ                            │
│   ├ 画面（Flutter）                                │
│   ├ 状態（Riverpod）── 端末・位置・イベントを保持    │
│   ├ REST クライアント（dio）── 一覧・履歴・設定      │
│   ├ WebSocket ── 位置・状態・イベントをリアルタイム受信│
│   └ 通知（FCM）── アプリを閉じていても届く           │
└───────────┬──────────────────────┬───────────┘
            │ HTTPS                 │ プッシュ
            ▼                       │
  https://<PC名>.ts.net（Tailscale Funnel）
            │                       │
            ▼                       │
  ┌─ 本番 PC ─────────────────┐     │
  │ Traccar  REST /api/*        │─────┘ Firebase 経由で通知
  │          WebSocket /api/socket │
  │ PostgreSQL                   │
  └──────────────────────────────┘
```

### 利用する Traccar API

| 用途 | API |
|---|---|
| ログイン | `POST /api/session`（メール・パスワード）→ `POST /api/session/token`（長期トークン発行） |
| 再ログイン | `GET /api/session?token=...`（アプリ起動時、保存したトークンで自動ログイン） |
| 端末一覧・追加・編集 | `GET/POST/PUT /api/devices` |
| 最新位置 | `GET /api/positions` |
| リアルタイム | `WS /api/socket`（`devices` / `positions` / `events` を受信） |
| 住所 | `GET /api/server/geocode?latitude=&longitude=` |
| 履歴（ルート・停車・トリップ・集計） | `GET /api/reports/route` / `stops` / `trips` / `summary` |
| アラーム履歴 | `GET /api/reports/events` |
| 通知設定 | `GET/POST/PUT/DELETE /api/notifications` |
| ジオフェンス | `GET/POST/PUT/DELETE /api/geofences` ＋ `POST /api/permissions`（端末との紐付け） |
| コマンド | `GET /api/commands/types?deviceId=` ／ `POST /api/commands/send` |
| 位置共有 | `POST /api/share/device`（期限付きトークン → 共有リンク） |
| プッシュ通知の登録 | `PUT /api/users/{id}` の属性 `notificationTokens` に FCM トークンを追加 |

## 6. 主要画面の詳細

### S2 ホーム（地図）— TrackerOne のメイン画面に相当

```
┌──────────────────────────────┐
│ 👤   [ 地図 | 一覧 ]        🔔③ │  ← 上部タブ、未読アラーム数
├──────────────────────────────┤
│                       [地図種類]│
│        ● 車                     │  ← 端末アイコン（向き付き）
│                         [ ▲ ]  │  ← 前/次の端末へ
│                         [ ▼ ]  │
│                         [ ◎ ]  │  ← 自分の現在地
├──────────────────────────────┤
│ 車        [停車中 23分]         │  ← 状態バッジ
│ 東京都千代田区丸の内1丁目        │  ← 住所（タップで更新）
│ GPS ▂▄▆  エンジン ON  電池 80%   │
│ 最終更新 12:34（1分前）          │
├──────────────────────────────┤
│ 履歴再生  詳細  共有  コマンド   │
└──────────────────────────────┘
```

| 表示 | データの出どころ |
|---|---|
| 状態バッジ | `device.status`（online/offline/unknown）＋ 位置の `motion` 属性。停車時間は最後の `deviceStopped` イベント時刻から計算 |
| 住所 | `/api/server/geocode`（アプリ内でキャッシュ。移動 50m 未満なら再取得しない） |
| GPS | `attributes.sat`（衛星数）を3段階表示。`valid=false` なら「測位なし」 |
| エンジン（ACC） | `attributes.ignition` |
| 電池 | `attributes.batteryLevel`（%） |
| 速度 | `speed`（Traccar はノット → km/h に換算 ×1.852） |

### S4 履歴再生

- 日付: 「今日」「昨日」「日付を選ぶ」（開始・終了時刻も指定可）
- `reports/route` で位置列を取得 → 地図に線（走行=青緑、停車地点=番号付きマーカー）
- `reports/stops` で停車地点と停車時間、`reports/summary` で総距離・最高速度
- 再生: 再生/一時停止、シークバー、速度 1x/2x/4x/8x、現在時刻と速度を表示
- 書き出し: GPX ファイルを共有（他の地図アプリで見られる）

### S7 アラーム一覧（イベント → 日本語）

| Traccar のイベント | アプリでの表示 |
|---|---|
| `geofenceEnter` / `geofenceExit` | 「〇〇エリアに入りました／出ました」 |
| `deviceOverspeed` | 「速度超過（85 km/h）」 |
| `alarm`（`sos`） | 「SOS」 |
| `alarm`（`vibration`） | 「振動を検知」 |
| `alarm`（`powerCut`） | 「電源が切断されました」 |
| `alarm`（`lowBattery`） | 「電池残量が低下」 |
| `alarm`（`tampering` / `removing`） | 「取り外しを検知」 |
| `ignitionOn` / `ignitionOff` | 「エンジン ON／OFF」 |
| `deviceOnline` / `deviceOffline` | 「通信を再開／通信が途絶えました」 |
| `deviceMoving` / `deviceStopped` | 「移動を開始／停車しました」 |

一覧は日付ごとに区切り、種類別のアイコン色（赤=SOS・取り外し、橙=速度・電源、青=エリア、灰=通信）で見分けられるようにする。

### S10 ジオフェンス

- 円: 地図をタップして中心を決め、スライダーで半径（50m〜5km）
- 多角形: 地図をタップして頂点を追加
- 名前、対象の端末、通知（入る／出る／両方）を設定
- 保存形式は Traccar の WKT（`CIRCLE (緯度 経度, 半径m)` / `POLYGON((...))`）

### S11 コマンド

- `commands/types` で端末が対応するコマンドだけを表示（GT06 系: エンジン停止・エンジン再開・任意コマンド など）
- 日本語名と説明を表示。**エンジン停止は「走行中に使うと危険です」の確認を2回**出す
- 送信結果（送信済み／端末が圏外のため保留）を表示し、履歴を残す

### S13 発信機の SMS 設定（TrackerOne の「サーバー切替」に相当）

- 端末に登録した SIM 電話番号あてに、スマホの SMS アプリを文面入りで開く
- テンプレート: サーバー接続先（`SERVER,1,<ドメイン>,<ポート>,0#`）、状態確認（`STATUS#`）、位置確認（`WHERE#`）など
- 文面は機種によって違うため、**編集してから送れる**ようにする

## 7. 通知の仕組み

```
発信機 ─▶ Traccar がイベント検知 ─▶ 通知設定（firebase）に一致
      ─▶ Firebase ─▶ スマホに通知 ─▶ タップでアラーム詳細を開く
```

1. Firebase で無料プロジェクトを作成（カード登録不要）
2. Traccar の設定に Firebase のサービスアカウントを登録（`notificator.types=web,firebase` と `notificator.firebase.serviceAccount`）
   → install.ps1 の設定項目に追加する（サーバー側の追加作業）
3. アプリはログイン後に FCM トークンを取得し、ユーザー属性 `notificationTokens` に追加
4. ログアウト時はトークンを削除（別の人に通知が届かないように）

通知の文面は Traccar のテンプレートを日本語版に差し替える（サーバーの `templates/full/*.vm` を上書き）。

## 8. セキュリティ

| 項目 | 対策 |
|---|---|
| 通信 | HTTPS のみ（Tailscale Funnel の正規証明書）。例外として、LAN 内テスト用に設定で `http://` を許可できるが、本番では無効 |
| ログイン情報 | パスワードは保存しない。発行したトークンだけを暗号化保存（flutter_secure_storage） |
| トークン期限 | 1年。ログアウトで失効（`/api/session/token/revoke`） |
| 共有リンク | 期限付き（最大7日）。期限が切れたら見られない |
| 危険なコマンド | エンジン停止は二重確認 |
| 権限 | 位置（自分の現在地表示用、任意）、通知、カメラ（QR 読み取り時のみ） |

## 11. 開発の進め方

| 段階 | 内容 | 完成の目安 |
|---|---|---|
| 1. 土台（MVP）✅ | プロジェクト作成、アイコン、ログイン、地図・一覧、端末カード、リアルタイム更新 | テスト PC の Traccar に接続して、テスト位置が地図に即時表示される（2026-10-24 エミュレーターで確認） |
| 2. 履歴 ✅ | 履歴再生、停車地点、距離集計、GPX 書き出し | 昨日のルートを再生できる（2026-10-24 エミュレーターで確認） |
| 3. 通知・アラーム | Firebase 連携、アラーム一覧・詳細、通知設定、日本語テンプレート | アプリを閉じていても SOS 等の通知が届く |
| 4. ジオフェンス | 作成・編集・通知 | エリアの出入りで通知が届く |
| 5. 操作系 | コマンド、位置共有、端末設定、SMS 設定、端末追加 | 共有リンクを LINE で送って相手が見られる |
| 6. 仕上げ | ダークモード、圏外・通信断の表示、テスト、APK 署名と配布手順 | GitHub Releases から APK を入れて使える |

### テスト
- 単体テスト: 単位換算、イベントの日本語化、停車時間の計算、WKT の作成
- 結合テスト: テスト PC の Traccar（`install.ps1 -TestMode`）に OsmAnd 方式でテスト位置を送り、画面に反映されるか
- 実機テスト: お手持ちの WanWay 発信機（本番サーバー接続後）

### 開発に必要な無料ツール（段階1で導入）
- Flutter SDK、Android Studio（Android SDK・エミュレーター）、Git
- 実機確認用に、いまつないでいる Android スマホ（USB デバッグ済み）を使用
